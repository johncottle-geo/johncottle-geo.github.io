John Cottle website
===================
Static site, no build step. Open index.html in a browser to preview.

Deploy free:
  Netlify:      drag this whole folder onto app.netlify.com/drop
  GitHub Pages: create a repository, upload the contents of this folder
                (index.html at the top level), then Settings > Pages > main branch.
  Cloudflare Pages: Workers & Pages > Create > Pages > Upload assets.

Files:
  index.html and the other .html pages  (same file names as the old Weebly site)
  assets/style.css   colours and layout (UCSB navy and gold at the top of the file)
  assets/img/        resized photos from the old site
